## 每章驗收條件

1. **原文與情節**：完整閱讀英文正文；確認人物關係、時間線、因果、章末承接、結尾及設定一致，修正套版或跨章重複。
2. **語言**：校正英文語法、搭配、對話自然度及級距適合性；不得靠無意義重複湊字數。
3. **英中一致**：逐段與中文對照，檢查漏譯、增譯、指稱、數字、語氣、專名。
4. **單字教學**：英文正文至少 500 詞；目標詞至少 20 個且確實出現在正文；單字解釋與使用脈絡一致。
5. **閱讀測驗**：每章兩題的題幹、正確選項、干擾選項、中文解析須能由正文支持；逐題標出證據。
6. **發版與簽核**：修改原始內容、生成網站資產、執行專案測試及來源 SHA 驗證；上述工作完成後才可核准簽核或變更 `learningReviewRequired`。
