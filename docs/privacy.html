隱私政策

更新日期：2026 年 11 月 8 日。適用於拾頁 StorySteps 的 GitHub Pages 網站。

本機學習紀錄

互動版使用瀏覽器 localStorage 保存閱讀進度、生字、書架、句子收藏、閱讀設定、簽到與解鎖。這些資料不會自動在不同裝置同步；清除網站資料可能刪除紀錄，可先到閱讀中心下載備份。

自願閱讀研究與勘誤

同意參加研究後，網站會向 Cloudflare Workers 傳送隨機瀏覽器識別碼、開書、章節完成、下一章、難度及解鎖等事件，保留 90 天；不傳送姓名、查詞文字或故事正文。可在互動版資料說明中停止後續傳送。段落勘誤在按下送出時傳送書名、章節、段落位置、類型與文字，保留 90 天。清除本機紀錄不會自動刪除已傳送資料；如需詢問請使用下方聯絡頁，勿公開個資。

Google 廣告

網站已安裝 Google AdSense 程式碼供網站驗證與廣告服務，是否通過審核及是否有可用廣告取決於 Google。Google 與第三方廣告供應商可能使用 Cookie、IP 位址、裝置或其他識別碼、網站瀏覽資訊提供、衡量及個人化廣告；廣告程式載入時可能處理連線資料。不能把「未顯示廣告」理解為完全沒有第三方連線。

Google 可能依據使用者先前造訪本網站或其他網站的資訊投放廣告。可透過 Google 廣告設定管理個人化廣告，也可透過第三方停用網站管理部分供應商的個人化廣告。瀏覽器設定可限制 Cookie；可能影響部分功能。

其他服務

GitHub Pages 與 Cloudflare 會依各自政策處理提供服務所需的連線與安全資料。互動版可能載入 Google 字型。朗讀由瀏覽器／系統語音服務提供；外部字典僅在你開啟其連結後使用其服務。外部服務的資料處理由各自隱私政策規範。

公開聯絡管道

GitHub 問題追蹤區的內容是公開的，需 GitHub 帳戶。請勿填入姓名、電話、密碼、學習備份或其他個資。如需非公開處理，請先僅提出聯絡需求，由維護者安排後續方式。
