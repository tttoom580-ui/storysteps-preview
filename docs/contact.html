在 GitHub 留下問題或聯絡需求

需要 GitHub 帳戶。送出後內容及帳戶名稱公開可見，請勿填入電話、密碼、付款資料、學習備份或其他個資。目前尚無公開的獨立商業合作信箱；請勿在公開 Issue 貼合約或個人資料。私密商務聯絡管道設立後再處理正式商業資料。

內容勘誤請提供

  • 書名、章節及固定網址。
  • 有問題的英文句子、翻譯或測驗題。
  • 你認為需要修改的地方。

目前已暫停雲端段落文字回報；段落工具提供書名、章節與段落位置，供你自行決定是否到公開 GitHub 管道回報。頁尾的一般「意見回饋」目前只存本機，不會自動送達站主，因此正式聯絡請使用上方 GitHub 管道。
