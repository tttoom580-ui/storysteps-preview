聯絡與勘誤

拾頁由本專案 GitHub 儲存庫擁有者維護。內容勘誤、功能故障與一般合作詢問，可透過下方公開問題追蹤區傳達給維護者。

在 GitHub 留下問題或聯絡需求

需要 GitHub 帳戶。送出後內容及帳戶名稱公開可見，請勿填入電話、密碼、付款資料、學習備份或其他個資。需要非公開聯絡時，請先只說明需求，由維護者安排後續方式；目前不提供站內私訊。

內容勘誤請提供

  • 書名、章節及固定網址。
  • 有問題的英文句子、翻譯或測驗題。
  • 你認為需要修改的地方。

互動版段落旁的「這段有問題？回報」會在你送出後傳到站主的勘誤資料庫。頁尾的一般「意見回饋」目前只存本機，不會自動送達站主，因此正式聯絡請使用上方 GitHub 管道。

依自己的步調閱讀。前 5 章可直接閱讀；互動版提供查詞、收藏、朗讀與後續免費解鎖。
