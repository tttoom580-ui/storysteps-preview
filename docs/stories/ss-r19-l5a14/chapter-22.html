The repair technicians found a hidden program that wrote fragments of stored memory back into each patient after treatment. It had been designed as a safeguard, but someone had changed its priorities. The program preferred familiar stories over uncertain events; it filled gaps with the simplest shared record. That could explain the crew's identical description of the violet planet and their inconsistent private lives. Lu Sha asked that the code be preserved and reviewed independently before deletion. A rushed shutdown might erase the only remaining traces of the missing years. The technicians isolated it from the active medical system and built a test environment. In the test, a simulated patient remembered a garden but forgot the person sitting beside him. Arsen watched quietly. "I know the garden," he said. "Now I want to learn who the people were."
