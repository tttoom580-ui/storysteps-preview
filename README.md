# 拾頁 StorySteps · GitHub Pages

沿用原始拾頁網站的 React 介面、紫色設計、44 本書目與 39 張原版封面。

## 可用功能
- 九個導覽頁面、級距與題材搜尋、書籍收藏
- 120 個現有試讀章節（各書最多前 5 章，未完稿書籍依現有章數）
- 中英段落對照、內建查詞、生字收藏與間隔複習、瀏覽器朗讀
- 本機閱讀紀錄、閱讀中心、JSON 備份與還原、句子分享卡
- 本機護照與內容統計預覽

原專案共找到 500 個章節、19 本 25 章完整作品。公開版僅匯出 120 個試讀章節，不包含第 6 章以後正文。沒有把未完成作品標為完稿。

## 限制
GitHub Pages 是靜態網站。此版本沒有正式登入、跨裝置同步、付款、通行碼、公開留言、全站排行榜或正式管理後台；相關頁面保留設計並標示尚未啟用。管理頁顯示的是本機資訊，不提供任何管理權限。

資料保存在此網站的瀏覽器儲存空間，請使用閱讀中心備份。購書頁不接受真實付款，通行碼啟用按鈕停用。查詞未收錄時，可手動開啟外部字典。

## 開發
安裝 Node.js 22.13+ 後：

```sh
npm install
npm run dev
npm run build
```

建置輸出為 `docs/`，GitHub Pages 使用 `main` 的 `/docs`。程式碼與公開試讀資料均可直接修改再建置。

封面從原始專案 PNG 壓縮為 WebP，保留原構圖。原私人 storysteps 專案與 Cloudflare 正式環境未改動。
