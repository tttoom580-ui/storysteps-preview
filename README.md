# 拾頁 StorySteps · 免費閱讀版

82 本完整可讀小說、2,050 個雙語章節、82 張封面。保留紫色品牌，手機使用底部五個入口及「更多」選單；書庫雙欄、可收起題材篩選、閱讀工具列獨立橫向捲動、大字體與44px以上主要按鈕。

## 閱讀模式

所有功能免費。各書前5章直接讀；其後分成6–9、10–13、14–17、18–21、22–25五個區段，每次獎勵解鎖4章。已解鎖區段可在此瀏覽器持續重讀。清除網站資料會清除解鎖。

目前尚未設定正式廣告單元，因此明確提供「免廣告免費解鎖」。這不是廣告觀看，不產生廣告收入，也沒有倒數計時模擬廣告。

完整書籍資料按書分別壓縮、依需要載入，目前提供2,050章。這是GitHub Pages的靜態免費網站：資料檔可公開取得，前端解鎖控制正常閱讀流程，不是保密或防作弊機制。

查詞、逐段翻譯、瀏覽器朗讀、生字間隔複習、書架、閱讀足跡、JSON備份與還原都免費。章末心情與心得僅存於本機，不冒充公開評論；本機統計不是全站數據。自願啟用的匿名同步金鑰功能使用獨立 Cloudflare Worker 與 D1 保存進度、詞彙、書架、簽到及免費解鎖；同步資料無端對端加密，並不驗證獎勵解鎖來源。未開啟同步時所有資料仍保存在瀏覽器。

## 開發與發布

Node.js 22.13+：npm install、npm run dev、npm run build。輸出docs，GitHub Pages使用main的/docs。mobile-qa.html屬暫時的內部排版驗證檔，不納入發布。

資料入口：public/catalog.js、public/content-manifest.json、public/books/*.bin（gzip）。同名來源檔在建置時複製至docs。

## 啟用正式獎勵廣告

取得核准網站可用的Google Ad Manager獎勵廣告單元後，更新public/rewarded-config.json，再建置發布：

```json
{"enabled":true,"adUnitPath":"/YOUR_NETWORK_ID/YOUR_REWARDED_UNIT","allowFreeFallback":true}
```

這是欄位示意，不可把示意路徑當成真實廣告單元。沒有設定時維持enabled:false。

SDK只在使用者點擊「觀看廣告，解鎖4章」後載入。獎勵由rewardedSlotGranted確認；單純關閉不會解鎖，載入或無填充錯誤不會記為觀看。若allowFreeFallback=true，無廣告時另讓使用者選擇免費解鎖。一次僅有一個獎勵請求，具備逾時、空廣告、裝置不支援、取消與事件清理處理。

實際廣告形式、時長、填充與收益由平台、廣告需求及流量決定，不能承諾固定30/60秒；僅供影片需求的設定可能需由Ad Manager帳戶端另外處理。沒有設定Ad Manager帳號或網路編號就不能開始賺取廣告收益。

正式高流量情境可接入Google的SSV伺服器驗證及後端解鎖憑證；目前不宣稱前端回呼具備防偽驗證。

官方參考：https://developers.google.com/publisher-tag/samples/display-rewarded-ad
https://support.google.com/admanager/answer/9116812

## 廣告收入試算方式（非行情或保證）

月收入＝每日活躍讀者×每人每日廣告請求×實際播出率×30×出版者每千曝光收入÷1000。

| 情境 | 請求／人／日 | 實際播出率 | 每千曝光收入（假設NT$） |
|---|---:|---:|---:|
|低|0.5|40%|30|
|中|1|60%|80|
|高|1.5|80%|150|

以上均為敏感度分析參數，不是台灣市場報價。完成率用來計算解鎖獎勵，不直接再乘到以曝光為分母的收入公式，避免混淆。展示廣告收入未列入。

目前每本只有5組獎勵區段。全82本最多410次首次區段解鎖；既有讀者重讀已解鎖章節不再需要廣告，新書更新及持續取得新讀者會影響收入。

正式廣告尚未接通，當前廣告收入為0。試算未扣自有維運支出與稅費，不等同獲利。

## 2026-11-13 跨裝置同步（新增）

- 備份中心可建立匿名同步空間、顯示及複製復原金鑰，也可在第二台裝置貼上相同金鑰合併資料。相同金鑰是唯一認證方式，請勿公開分享；遺失金鑰無法找回。
- 同步不蒐集使用者電子郵件、姓名或密碼。伺服器將高熵金鑰做 SHA-256 雜湊儲存；學習資料保存在 Cloudflare D1，並未端對端加密。
- 使用帶 revision 的樂觀鎖防止兩台裝置直接覆寫；合併衝突會重新讀取雲端資料。離線可繼續使用本機閱讀與備份。
- 後端原始碼：sync-service/worker.mjs；資料表：sync-service/schema.sql。此機制仍需實機雙裝置端到端測試，不應宣稱已全面驗證。
- 正式獎勵廣告仍為 disabled；需要平台已核准的真實 rewarded ad unit 才能啟用。
